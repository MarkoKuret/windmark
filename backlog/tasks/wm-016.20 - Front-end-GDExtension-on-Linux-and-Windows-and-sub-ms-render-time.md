## Description

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
AC #2: the C API render queries (wm_world_wind_state, wm_world_puffs_at, wm_world_current_at, wm_world_sea_height_at) take double ms (WM_API_VERSION 6). Sea height and the tide phase are evaluated exactly at the fraction (sea.md 7.2); wind direction and puff patches are lerped between the neighbouring whole ms (wind.md 9 render time). Whole ms give the tick values bit for bit; the fixed-tick sim is unchanged. GDExtension CoreSim and CoreSimSource pass fractional times. Tests: core/tests/test_capi_render_time.cpp, game/tests/core_sim_test.gd.
